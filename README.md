# Minecraft Helden

Paper-Plugin für Minecraft 1.21.1 (Java 21).

## Build
Mit installiertem Gradle im Projektordner:
`gradle build`

Die fertige JAR liegt anschließend unter `build/libs/`.

## Befehle
- `/helden` oder `/helden liste` – Helden-GUI öffnen
- `/helden waehlen <held>` – Held auswählen
- `/helden info` – Informationen zum gewählten Helden

Der Alias `/hero` bleibt als Kurzform verfügbar.

Hinweis: Die Heldenauswahl, GUI und Speicherung der Auswahl/Leveldaten sind enthalten. Die in den Beschreibungen genannten Spezialfähigkeiten sind aktuell Platzhalter und müssen noch mit konkreten Effekten programmiert werden.
